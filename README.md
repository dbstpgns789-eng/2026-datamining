# 2026-datamining

INE5006 데이터마이닝 팀과제 저장소 (5팀).

| 폴더 | 과제 | 마감 |
|---|---|---|
| `project01/` | HW1 — Q1 2-head word, Q2 int-pair, Q3 World Happiness | 2026-10-13 23:59 |

## 작업 방식

1. 각자 세 문제 전부 풀어 `drafts/<자기 아이디>/`에 push (~10/8). 코드리뷰 인터뷰에서 누구든 설명해야 하므로 분담 금지.
2. 10/9~10 모여서 리뷰. 문제마다 제출본을 고르고, 고른 사람이 아니어도 설명 가능한지 확인.
3. 제출본을 `project01/`에 push (~10/12). 출력 셀 포함 확인.
4. 마감 10/13 23:59.

규칙: 강의에서 다룬 Spark API만 사용. 마지막 action 외 모든 단계는 Spark 연산. `.ipynb`는 출력 셀을 포함한 채로 올린다.
