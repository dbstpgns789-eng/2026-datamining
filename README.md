# 2026-datamining

INE5006 데이터마이닝 팀과제 저장소 (5팀).

| 폴더 | 과제 | 마감 |
|---|---|---|
| `project01/` | HW1 — Q1 2-head word, Q2 int-pair, Q3 World Happiness | 2026-10-13 23:59 |

## 공식 일정 (교수님)

- 제출 마감 **2026-10-13(월) 23:59**
- 코드리뷰 **2026-10-14(수) 수업**

## 작업 방식 (팀 제안, 날짜는 팀에서 조정)

1. 각자 세 문제 전부 풀어 `drafts/<자기 아이디>/`에 push. 코드리뷰 인터뷰에서 누구든 설명해야 하므로 분담하지 않는다. **각자 풀이 데드라인 = 팀 코드리뷰 전날 24:00** (리뷰일이 정해지면 여기에 적는다).
2. 모여서 리뷰. 문제마다 제출본을 고르고, 고른 사람이 아니어도 설명 가능한지 확인.
3. 제출본을 `project01/`에 push. 출력 셀 포함 확인. 마감 하루 전까지를 목표로.

규칙: 강의에서 다룬 Spark API만 사용. 마지막 action 외 모든 단계는 Spark 연산. `.ipynb`는 출력 셀을 포함한 채로 올린다.
